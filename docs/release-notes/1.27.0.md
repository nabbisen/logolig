# Logolig 1.27.0 — release notes

Status: **release candidate** (prepared for the owner's decision; not tagged or published).

## Highlights

- **Non-square logos are shown in full.** A logo that is not square is no longer cut or stretched in the square outputs; it is scaled to fit and centred on a transparent square, and Logolig tells you when it does so.
- **Keyboard shortcuts** for the main task: choose a file, download all, go back, switch pages, and a list of them in Settings.
- **Large and photographic images convert quickly** and no longer freeze the window's shortcuts.
- **SVG sources are read more safely**: files that an SVG refers to are not read from your computer, and Logolig says which parts of an SVG are not shown.
- **Messages stay long enough to be read**, and warnings are easier to read.
- **A source package for Arch Linux** (AUR `logolig`) is prepared; it is not yet published.

## Changes by area

### Output

- A non-square PNG, WebP, JPEG or SVG is scaled to fit inside the square and centred on a transparent canvas, for the favicon PNGs, the ICO frames and the previews (RFC 010). **The favicon of a non-square logo therefore looks different from 1.26.x.** A square source is processed exactly as before.
- When the sides differ by more than 2 %, one advisory says that the logo is shown in full with empty space around it, so the icon may look small, and suggests a square version.
- "Download all (ZIP)" no longer fails when monochrome output is on, and a failed save no longer leaves a half-written archive: the ZIP is built in memory and written in one step, and every file keeps its folder (for example `mono/`) (RFC 009).

### Conversion

- For `favicon.svg`, a raster whose longest side is more than 512 px is scaled down before it is traced, because tracing time and output size grow faster than the pixel count. A large flat logo's `favicon.svg` therefore declares 512 px. Rasters of 512 px or less are traced exactly as before, and the PNG and ICO outputs are always made from the full source image (RFC 030).
- For a noisy test image of 1400 px the tracing step went from about 10 s to well under a second, and the `favicon.svg` from 25 MB to under 2 MB.
- The conversion runs on a worker thread, so keyboard shortcuts and other window events are served while a large image converts (RFC 030).
- `favicon.svg` of a photograph is an approximation and can still be large (about 3 MB for a very noisy image). Turn off "SVG output" in Customize if you do not need it.
- SVG sources: images that an SVG refers to by file path are no longer read from your computer (embedded images still work). Text inside an SVG is not drawn yet. One advisory tells you which of the two applies (RFC 015 phase 2a). `favicon.svg` of an SVG source is still a verbatim copy of your file.

### Keyboard

- **Ctrl+O** (Cmd+O on macOS) choose a file; **Ctrl+S** download all (ZIP); **Esc** close the newest message, or go back to the start screen; **Ctrl+1 / 2 / 3** Home, Customize, Settings; **F1** the Settings page, which lists these shortcuts (RFC 019 phase 2).
- A shortcut works only when the button it stands for is available; holding a key down does nothing.
- Limits: moving between buttons and fields with **Tab**, activating them with Enter or Space, a visible focus indicator, and the Customize page without a mouse are **not** in this release (RFC 027 is planned). While a text field has focus, it takes some keys first: Ctrl+1 types a "1" and Ctrl+O does nothing.

### Look

- Notifications were redrawn (snora 0.53): the warning notification now has dark text on an amber background (contrast about 6:1, up from about 3.2:1), the text follows the application's text size, and the close button is larger. A click on a notification no longer reaches the widget underneath it (RFC 028).
- A notification now stays for a time that follows the length of its text, between 4 and 20 seconds (the long advisories stay 12 to 20 seconds); error notifications still stay until you close them (RFC 029).
- Application ID: the window reports `io.github.nabbisen.Logolig` (on Linux, so that desktop environments can match it to the desktop entry) (RFC 025).

### Packaging

- An AUR source package `logolig` is prepared (build recipe, desktop entry and icons); a CI job builds and checks it. It is **not yet published**.
- It needs a system font (the interface text uses system fonts) and, for the file chooser, an XDG desktop portal with a backend (`xdg-desktop-portal-gtk` or the one of your desktop). **Without a portal "Choose file…" does nothing and shows no message** (known; RFC 031 is proposed).

### Under the hood

- Minimum supported Rust version is now 1.90 (declared and checked in CI) (RFC 024).
- Dependencies updated: `zip` 9, `tokio` 1.54, `snora` 0.53, and three other lock updates. `cargo audit` reports 0 vulnerabilities and 12 triaged warnings.
- Continuous integration runs five jobs (format, clippy, tests, MSRV build, audit) plus a packaging job (RFC 020).
- 253 automated tests.

## Known limitations

- **The Japanese texts added in this release have not had a native review**: the non-square advisory, the SVG advisory, and the keyboard shortcut list.
- Text inside an SVG is not drawn.
- No full keyboard navigation (see Keyboard).
- "Choose file…" and the Save dialogs give no message when no desktop portal is available (see Packaging).
- A notification can cover part of a result card, and on a small window the "Back" button can be partly cut off when the result list wraps to three rows (RFC 026 is proposed).
- The error notification for an unsupported file shows the whole file path (RFC 014 is proposed).
- Windows and macOS were not exercised in this release cycle; the macOS shortcuts use Cmd by design and are not verified.

## Upgrade notes

- No new setting was added and the saved settings format is unchanged.
- Favicons of non-square logos look different (fitted, not stretched). `favicon.svg` of a raster larger than 512 px declares 512 px.
- The Microsoft Store manifest version (`packaging/windows/AppxManifest.xml`) is separate and is not changed by this release preparation.
