# Logolig 1.28.0 — release notes

## Highlights

- **Everything can be done from the keyboard.** Tab and Shift+Tab reach every control in the order of the screen, a visible ring shows where the focus is, Enter and Space act like a click, and the arrow keys choose within a group of choices.
- **Shortcuts never type into a text field.** Ctrl+1, for example, used to type a "1" into the custom-size field; now it goes Home.
- **A new application icon**, and clearer selection controls: checkboxes with a tick, radio-style groups, and a bar beside the active page in the navigation.
- **The Result screen keeps "Back" at the top and "Download all (ZIP)" at the bottom**, and the Settings page scrolls instead of squeezing its rows in a small window.
- **A newer file always wins**: the result of an older conversion that is still running can no longer replace it, and a missing file dialog is reported instead of staying silent.

## Changes by area

### Keyboard

- **Tab and Shift+Tab** move through the controls in the order they appear: the side navigation first, then the page. A ring marks the focused control, and the page scrolls so that the focused control is in view.
- **Enter and Space** press a button or toggle a checkbox. On a group of choices (theme, language, preview pickers, SVG conversion, resize algorithm) the **arrow keys** move the choice at once.
- **Command keys never type into a text field**: Ctrl+O (Cmd+O on macOS), Ctrl+S, Esc, Ctrl+1 / 2 / 3 and F1 act as shortcuts even while a field has focus. In 1.27.0 Ctrl+1 typed a "1" into the field and Ctrl+O did nothing.

### Look

- **New application icon** (Linux desktop icons, Microsoft Store tiles, README).
- **Selection controls were redrawn.** Checkboxes show a tick; choices in a group are radio-style; the active page in the navigation has a filled item, a bold label and an accent bar beside it. A state is never shown by colour alone.
- **Icons replace text symbols** for "busy" and "done", and the open/close arrow of the preview section.
- **One "SVG conversion" choice with three named presets** ("Sharp (logos, icons)", "Default (balanced)", "Photo-rich (gradients)") replaces the slider and the duplicate preset list. It is the same setting as before, so saved settings still load and keep their value.
- Notifications wait while the pointer rests on them.

### Layout

- On the **Result screen**, "Back" stays at the top and "Download all (ZIP)" stays at the bottom; the list of results between them scrolls.
- The **Settings page** scrolls as one page instead of squeezing its rows in a small window.
- **Customize** scrolls as one area; "Reset to defaults" stays in view below it.

### Behaviour

- **A newer file always wins.** Choosing or dropping a new file while an older one is still being converted drops the older result and any error from it.
- **One file dialog at a time.** A double Ctrl+S used to open two Save windows; now it opens one, and a file chooser and a Save window are never open together.
- **A missing file dialog is reported once.** When no file dialog can appear on Linux (no desktop portal, or a portal without a file-dialog backend, and no `zenity`), Logolig shows one notice instead of doing nothing. The notice for "Choose file…" points to drag and drop. The check is conservative: a dialog that exists but never answers still shows nothing.

### Under the hood

- The interface library `snora` is updated from 0.53 to 0.65.
- A headless layout test level checks every page at several window sizes in English and Japanese, and the focus order, ring and selection cues, without a display.
- `cargo audit` reports 0 vulnerabilities and 12 triaged warnings; one is new: `chrono` is flagged as unmaintained (it is used only for ZIP timestamps).
- 363 automated tests.

### Packaging

- The **Linux icons are the new artwork**, in sizes 32, 48, 64, 128, 256 and 512 pixels; the scalable SVG icon is gone.
- The Microsoft Store tiles were replaced. The Store manifest version (`packaging/windows/AppxManifest.xml`) is separate and was not changed.

## Known limitations

- **Screen readers are not supported** (the interface toolkit, iced 0.14, exposes no accessibility tree).
- **The application has no text-size or zoom setting of its own.** Use your operating system's display scaling; see the README for what was checked.
- **Windows and macOS were not exercised** in this release cycle. The keyboard was checked on Linux (niri compositor, Wayland and X11), with the English interface.
- **The new Japanese texts have not had a native review.**
- **Text inside an SVG is not drawn.**
- After Enter on a navigation item the page changes and no control has the focus; the next Tab starts at the first control.
- The missing-dialog notice cannot appear when a dialog service exists but never answers.

## Upgrade notes

- The saved settings format is unchanged; settings from 1.27.0 load as before. A retired size-override list in an old file is still accepted and is not written again.
- **For users of the `logolig` and `logolig-i18n` libraries:** the following are **deprecated** in 1.28.0 and kept until the next major version: `MessageKey::{PresetLabel, SvgConversionSimple, SvgConversionDetailed, ShortcutsLimitNote}`, `ThemeMode::next`, `ExportPlan::overrides`, `SizeOverride` and `PreviewContext::label`.
- `MessageKey` gained three variants (`ToastDialogUnavailableTitle`, `ToastDialogUnavailableChooserBody`, `ToastDialogUnavailableSaveBody`). The enum is not `#[non_exhaustive]`: an exhaustive `match` in your code needs the new arms.
