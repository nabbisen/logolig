# Handoffs for RFC 015

Governing RFC: [RFC 015](../../accepted/015-svg-text-and-external-resources.md). The handoffs are execution documents; the RFC remains the authority for design and for lifecycle status. If a handoff conflicts with its RFC, the RFC wins and the handoff is corrected (RFC 000).

Phase 1 handoff: verification spike (evidence only). The phase-2 handoff is written after the architect reviews the phase-1 evidence.

- [`implementation-handoff-phase-1-svg-spike.md`](./implementation-handoff-phase-1-svg-spike.md)

Review requests and evidence produced by the implementer are working material and are not stored here.
