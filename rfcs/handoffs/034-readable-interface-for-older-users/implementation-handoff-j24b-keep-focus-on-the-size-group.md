## The defect (your confirmation run, items 2 and 3)

Choosing a step with the arrow keys keeps the ring while the layout stays (Normal → Large) but **drops it when the layout switches** (Large → Extra large: sidebar → bottom bar; and back: Extra large → Large). The next arrow key then does nothing, and one Tab lands on the Language group, two Tabs away from where the user was. A ring that vanishes in the middle of the very gesture that changes the size is the confusion RFC 034 exists to remove. **Decision: (b), fix it** (not a release-notes limitation).
