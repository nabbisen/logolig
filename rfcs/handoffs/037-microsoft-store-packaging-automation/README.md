# Handoffs for RFC 037

Governing RFC: [RFC 037](../../accepted/037-microsoft-store-packaging-automation.md). If a handoff conflicts with its RFC, the RFC wins (RFC 000).

- [`implementation-handoff-phase-a.md`](./implementation-handoff-phase-a.md) (M1): the Store manifest version derived from the workspace version and guarded in CI.
- [`implementation-handoff-phase-b-windows-package.md`](./implementation-handoff-phase-b-windows-package.md) (B1): a Windows build and the first Windows tests in CI, and an unsigned `.msix` as a workflow artifact (spike first); also carries the one-line Japanese string fix ("favicon" in Latin letters).

Review requests and evidence produced by the implementer are working material and are not stored here.
