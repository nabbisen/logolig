# Handoffs for RFC 016

Governing RFC: [RFC 016](../../accepted/016-i18n-completeness-and-dead-keys.md) (with its SemVer amendment of 2026-11-22). If a handoff conflicts with its RFC, the RFC wins (RFC 000).

- [`implementation-handoff-k4.md`](./implementation-handoff-k4.md) (K4): no hardcoded user-visible text and a guard that keeps it so; nothing is removed or renamed (the unused keys are listed in a fixture until 2.0).

Review requests and evidence produced by the implementer are working material and are not stored here.
