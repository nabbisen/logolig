# Handoffs for RFC 011

Governing RFC: [RFC 011](../../accepted/011-conversion-job-identity.md). The handoffs are execution documents; the RFC remains the authority for design and for lifecycle status. If a handoff conflicts with its RFC, the RFC wins and the handoff is corrected (RFC 000).

- [`implementation-handoff.md`](./implementation-handoff.md) (J11): job identity for asynchronous results, the input policy while a job runs, and "a file chooser is already open".

Review requests and evidence produced by the implementer are working material and are not stored here.
