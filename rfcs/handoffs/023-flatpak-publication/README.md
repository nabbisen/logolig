# Handoffs for RFC 023

Governing RFC: [RFC 023](../../accepted/023-flatpak-publication.md). The manifest and the Flathub submission are the owner's, written without AI assistance (D3); the handoffs here cover only what the dev team may do.

- [`implementation-handoff-f0-remove-aur.md`](./implementation-handoff-f0-remove-aur.md) (F0): remove the AUR packaging the owner dropped.
- [`implementation-handoff-f1-upstream-files.md`](./implementation-handoff-f1-upstream-files.md) (F1): MetaInfo, desktop file, validation workflow and a MetaInfo version guard. **No manifest.**
- [`implementation-handoff-f2-saved-path-in-the-sandbox.md`](./implementation-handoff-f2-saved-path-in-the-sandbox.md) (F2): the saved-file message must show the file name, not a document-portal path (found in the owner's Flatpak run).

Review requests and evidence produced by the implementer are working material and are not stored here.
