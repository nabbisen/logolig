# Handoffs for RFC 019

Governing RFC: [RFC 019](../../accepted/019-keyboard-accessibility.md). The handoffs are execution documents; the RFC remains the authority for design and for lifecycle status. If a handoff conflicts with its RFC, the RFC wins and the handoff is corrected (RFC 000).

Phase 1 handoff: run-time verification and honest documentation (done). Phase 2 handoff: global shortcuts and the in-app list (job J4). The focus model (Tab traversal, visible focus) is RFC 027.

- [`implementation-handoff-phase-1-keyboard-verification.md`](./implementation-handoff-phase-1-keyboard-verification.md)
- [`implementation-handoff-phase-2-global-shortcuts.md`](./implementation-handoff-phase-2-global-shortcuts.md)

Review requests and evidence produced by the implementer are working material and are not stored here.
