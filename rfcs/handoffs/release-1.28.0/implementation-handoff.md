## 1. Scope (you may change)

1. **Version:** `[workspace.package] version` in the root `Cargo.toml` `1.27.0` → `1.28.0`; `Cargo.lock` changes **only** the three workspace packages' versions (show the diff stat). `docs/src/functional-spec.md` and `docs/src/architecture.md`: the "1.28.0 (in preparation)" rows and any "described version" line become 1.28.0 (the architect's review of J15 verified them as "in preparation"). `packaging/windows/AppxManifest.xml` is **not touched** (its version is the owner's decision).
2. **Release notes:** new `docs/release-notes/1.28.0.md`, English, **no RFC numbers** (users do not know them; traceability is in `architecture.md` and the review files). Structure as 1.27.0's: Highlights (3–6 bullets), Changes by area, Known limitations, Upgrade notes. **Every statement must be supported by a review file or a test; leave out and report anything you cannot support.** Content to cover (check each against `git log 1.27.0..HEAD` and `.git-exclude/reviewed/`):
   - **Keyboard:** Tab and Shift+Tab reach every control in screen order; a visible focus ring; Enter and Space act like a click; arrow keys on groups of choices choose at once; the focused control scrolls into view; shortcuts (Ctrl+O, Ctrl+S, Esc, Ctrl+1/2/3, F1) never type into a text field (Ctrl+1 used to type a "1" into the custom-size field).
   - **Look:** new application icon (no RFC number; the owner's logo); selection controls redrawn (checkboxes with a tick, radio-style groups, a navigation bar on the active item); icons instead of text symbols for busy and success; one "SVG conversion" choice with three named presets (the slider and the duplicate preset list are gone; saved settings still load).
   - **Layout:** on the Result screen "Back" is always at the top and "Download all (ZIP)" always at the bottom; the Settings page scrolls instead of squeezing rows in small windows.
   - **Behaviour:** a newer file always wins over an older conversion still running (stale results and their errors are dropped); only one file dialog is open at a time (a double Ctrl+S opened two); when no file dialog can appear on Linux (no portal or no portal backend, no `zenity`) the application says so once and points to drag and drop; a toast waits while the pointer rests on it.
   - **Under the hood:** snora 0.65; headless layout tests; `cargo audit` 0 vulnerabilities with 12 triaged warnings (one new: `chrono` is flagged unmaintained, used only for ZIP timestamps).
   - **Packaging:** the Linux icons are the new artwork (sizes 32–512; the scalable SVG is gone); Microsoft Store tiles replaced (the Store manifest version is unchanged and the owner's call).
   - **Known limitations:** no screen-reader support (iced 0.14 exposes no accessibility tree); the application has no text-size or zoom setting of its own (use the operating system's display scaling; see the README); Windows and macOS were not exercised in this cycle; the keyboard checks were made on Linux (niri compositor, Wayland and X11), with an English interface; new Japanese texts have not had a native review; SVG text is not drawn.
   - **Upgrade notes (library users):** `logolig` and `logolig-i18n` are public: deprecated in 1.28.0 (kept until the next major): `MessageKey::{PresetLabel, SvgConversionSimple, SvgConversionDetailed, ShortcutsLimitNote}`, `ThemeMode::next`, `ExportPlan::overrides`/`SizeOverride`, `PreviewContext::label`; `MessageKey` gained variants (it is not `#[non_exhaustive]`; an exhaustive `match` in your code needs the new arms). Read the exact list from the code (`rg 'deprecated' crates`) and from `git diff 1.27.0..HEAD -- crates/core/src crates/i18n/src`, do not rely on this list.
